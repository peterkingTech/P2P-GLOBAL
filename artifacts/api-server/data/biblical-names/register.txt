# BIBLICAL NAMES, TITLES AND DESCRIPTIONS — the editable register (owner brief 2026-11-18).
# One entry per line, columns separated by " | ". Built and VERIFIED by scripts/build-biblical-names.mjs into
# data/biblical-names.txt: every reference is checked against the Bible text (BSB, KJV, ASV, WEB, YLT — all public
# domain, from bible.helloao.org), every Strong's number against the STEPBible lexicon (and whether it occurs in the
# primary verse), every Easton title against Easton's Bible Dictionary. Whatever fails is kept OUT of the verified
# data and listed as "needs verification" — nothing here is shown as fact unless a source confirms it.
#
# Columns:
#  1 id            unique, kebab-case
#  2 name          the expression as people search it
#  3 also          other spellings / renderings / searches (";" separated) — never counted as separate names
#  4 kind          name | title | description | metaphor | attribute | form | devotional | worship
#                    name/title  = the words stand in Scripture as a name or title
#                    description = a statement Scripture makes ("God is love"); metaphor = an image ("my rock")
#                    form        = a language form or translation rendering of another entry (Yahweh, Jehovah, Holy Ghost)
#                    devotional  = an expression believers use, BASED ON a passage (the basis is shown)
#                    worship     = a later worship / songwriting expression with no direct Scripture wording
#  5 persons       father | son | spirit | god  (god = the one God of Israel, persons not distinguished, or context-dependent)
#  6 sections      father, son, spirit, god, attributes, devotional  (A, B, C, D, E, F of the brief; G "original
#                  languages" and H "historical background" are computed from the data)
#  7 ref           primary passage (USFM book code), e.g. GEN 16:13 or ISA 9:6-7 ; empty = no Scripture wording
#  8 refs          other passages ";" separated. "@son" etc. says who is named there (Isa 44:6 the LORD, Rev 1:17 Jesus).
#                  A leading "~" marks a CONNECTED passage (no wording check: a New Testament use, a fulfilment, the setting)
#  9 phrase        wording that must appear in the passage in at least one translation; alternatives separated by " / "
# 10 strongs       STEPBible Strong's numbers (space separated; "A|B" = either form may be tagged)
# 11 easton        Easton's Bible Dictionary article title (verified to exist)
# 12 note          DRAFT P2P study note (speaker, setting, what it communicates) — shown as "awaiting editor review"
# 13 interp        interpretive / debated identification, translation differences, cautions — shown as such
#
